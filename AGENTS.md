# Repository instructions

## Site content register

`SITE_CONTENT.md` is the maintained content and implementation register for
this website.

Whenever a change affects `index.html`, public wording, claims, figures,
sections, navigation, links, branding, visual presentation, metadata,
`manifest.webmanifest`, `sw.js`, `CNAME`, assets, hosting, or deployment:

1. Review `SITE_CONTENT.md`.
2. Update every affected entry in the same commit as the site change.
3. Update its **Last reviewed** date and content-change log when applicable.
4. Keep proposed, in-progress, locally verified, and live production states
   explicitly distinguished.
5. Verify both the changed source and the deployed HTTPS page before reporting
   completion.

Do not transfer the `dsrailab.com` domain away from Squarespace. Do not modify
email-related DNS records without an explicit request for that exact change.
