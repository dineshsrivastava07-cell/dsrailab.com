# dsrailab.com

Official website source for [dsrailab.com](https://dsrailab.com).

## Hosting

- Hosted with GitHub Pages from the `main` branch and repository root.
- Custom domain declared in [`CNAME`](CNAME).
- HTTPS is provided and enforced by GitHub Pages.
- The domain remains registered and DNS-managed in Squarespace. Do not transfer
  the domain to GitHub or another registrar.

## Files

- `index.html` — production website.
- `CNAME` — GitHub Pages custom-domain configuration.

## Publish updates

Commit and push changes to `main`. GitHub Pages deploys the updated site
automatically.
